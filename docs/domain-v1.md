# Domain v1

BIM is the first explicit problem set. It is not the product category.

These repositories are computational-geometry frameworks for:

- industrial data integration
- computational instrumentation
- maintained evidence services

in manufacturing, infrastructure, agri-food, and logistics operations.

Construction acceptance is the bounded object used to freeze the contract:
declarations, units, refusal, first-order covariance, replay, and a named
project space. A later line, vessel, cold store, or yard uses the same
contract. It does not start by forking A2-A5 or inventing a second ledger.

## Mapping

| BIM demonstrator | Industrial object |
| --- | --- |
| project / building / space id | site, line, vessel, yard, cold store |
| IfcBeam / opening | tagged asset or fit-up interface |
| mill certificate | batch, heat, or lot certificate |
| `ObserveQuantity` | calibrated instrument record |
| `REQUEST_EVIDENCE` | missing measurement on a named slot |
| ledger head | maintained evidence identity |
| OpenUSD overlay | signed visual carrier, not the estimator |
| RCI bench | retrofitted instrument on a physical mechanism |
| FSRT tank balance | mass / energy / inventory closure |
| torus length | invariant of an object under change of representation |

## What does not change by sector

- JSPT owns the chart law and `J Sigma J^T`.
- Instruments produce records and digests. They do not prove.
- Means of derived quantities are re-evaluations.
- A digest is not a bind to an asset id until a typed bind exists.
- SP1 attests one arithmetic line, or it stays off.
- Dense Beam-B1 remains the oracle slice until a version bump.

## What does change by sector

Declarations: geometry, topology, measurement sigma, process-noise,
setpoints that enter the plant. Those live in the domain specification,
not in JSPT.

## Build order

1. Keep the BIM demonstrator and its ledger.
2. Keep RCI as telemetry with sigma and quality.
3. Keep OpenUSD as signed carrier plus visual.
4. Open factor-graph belief only after dense memory is the bottleneck.
5. Open pose or odometry factors only when a joint frame is a real IR slot.
6. Do not open a manufacturing / agri-food / logistics kernel until that
   sector has one bounded object, one declaration, and one pin.
