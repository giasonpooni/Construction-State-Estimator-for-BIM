# zkVM numerics v1

IEEE-754 inside a RISC-V guest is emulation. Do not prove a double-precision
geodesic. The first kernel is already the right shape: Beam-B1 F2-1 as
checked integers (`beam-milli-mpa-mm3-milli-nmm-v1`).

Admitted: checked u64/u128 products, host-side ties-to-even quantization,
scaled-integer recurrences.

Refused in a guest: f32/f64 as circuit arithmetic, general-metric RK4,
JSPT `push_covariance`, interval boxes until a host certificate exists.

Compare zkVMs by float/fixed-point cost and precompile need, not rollup
benchmarks. RISC-V as ISA outlives any one prover.
